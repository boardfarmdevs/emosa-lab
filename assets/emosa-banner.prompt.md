# EMOSA banner generation

- Tool: built-in image_gen (imagegen skill).
- Asset: `emosa-banner.png`.
- Purpose: GitHub README banner illustrating Japanese エモさ (*emosa*), loosely rendered as emotional resonance.
- EMOSA means EasyMesh to OpenSync Adapter; the Japanese expression is wordplay, not a translation of the name.
- Language reference: [Sanseido on エモい](https://dictionary.sanseido-publ.co.jp/topic/shingo2016/2016Best10.html).

## Final prompt

The original generation prompt below is preserved as provenance. It used an
incorrect expansion of EMOSA, corrected above on 2026-09-16. The banner itself
contains only EMOSA, エモさ and Emotional resonance, so its artwork is unchanged.

Use case: illustration-story.
Asset type: wide illustrated banner for the EMOSA GitHub README, approximately 2:1 landscape.
Primary request: create a beautiful picture expressing the Japanese word エモさ (emosa): emotional resonance, the moving and sometimes nostalgic quality of a moment. The project acronym is EMOSA, EasyMesh OVSDB Adapter; the illustration should express the Japanese word rather than a technical architecture.
Scene: a quiet Japanese riverside neighborhood at blue-hour sunset. A small footbridge joins the two banks; warm light glows in a few house windows and reflects in still water. Distant hills and a luminous fading sunset create an intimate, wistful sense of memory and connection.
Style: refined contemporary Japanese editorial illustration, softly painted shapes, delicate paper grain, restrained detail, atmospheric depth; polished and calm, not a busy tourism poster.
Composition: wide panoramic banner, uncluttered sky with generous negative space for readable integrated typography, scenery concentrated in lower half. Strong readability when shown at GitHub README width.
Text, exactly these three lines, elegantly integrated into the open sky:
"EMOSA"
"エモさ"
"Emotional resonance"
EMOSA is the largest line; Japanese second; English gloss smaller but clearly readable. Use clean carefully spaced typography, accurate Japanese glyphs, no extra writing.
Constraints: no corporate logos, no watermark, no additional text, no fake kanji, no technical diagrams, no cliché collage of Japanese landmarks. The mood should feel quietly moving and nostalgic, not sad or melodramatic.
